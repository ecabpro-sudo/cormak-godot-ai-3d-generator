# Cormak AI 3D Generator

Generate textured 3D models from a description or an object photo, then download
and import the GLB inside the Godot editor. The add-on is free and uses your
existing Cormak account and AI credits for cloud generation.

See the [full installation and usage guide](../../README.md).
